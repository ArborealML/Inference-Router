## Decision

Accepted implementation baseline: retain one router writer and existing ordered pending queues. Enumerate available alternatives and complete finite snapshot/continuation rounds before parking; probes are side-effect-free and preparation is scoped to one physical domain. Preserve queue-only priority, not provider economics, capacity or context policy. Omitted stateless identity is request-scoped, explicit named thread limits remain.

Router selects desired operating points and work; a host manager alone grants verified physical admission, lifecycle mutation and settlement within an externally established resource boundary. Establish the in-process composition/issuer seam before production admission and host qualification. TASK-25 owns the paired production witness with TASK-118's bound sender; host/peer integration consumes that pinned proof. Combined/router/manager roles use one Native AOT build. Static configured peer placement first; one ingress writer with forwarding, not distributed consensus. External deployment establishes singleton authority and protected ingress; no automatic takeover while the old writer can submit. Stale incarnations and ambiguous ingress replay refuse. Never infer vacancy or non-execution from heartbeat/timeout.

Choose context independently of admission target and physical launch lanes from qualified exact recipes. Use actual finite demand, comparable measured occupancy, transition and cache cost; do not assume lowering admission changes physical allocation. Required ladder is 64K, 96K, 128K, 196K, 256K, 512K, 768K, 1024K (binary K per decision-74), limited by demonstrated support. Cap each normal next-tier search by preceding measured optimum, with explicit exhaustive override; retain per-point evidence. Keep decision-81's one runner. Adopt explicitly by evidence hash and enabled mode; mixed/staggered production modes require representative real replays, and synthetic fixtures cannot confer capacity. Preserve active work and qualified conformance.

Authorized new inference policy groups default insensitive; scoped escalation is durable, privileged declassification checks externally supplied authority and current revision, and allow/deny filters intersect explicit trust. AIR consumes minimal independently authorized principal/root association, not agent hierarchy or human authentication. Disabled lowering alone does not prevent an otherwise authorized fixed insensitive root; enabled lowering requires independently established protected human authority. Agent orchestration supplies associations; sandbox/deployment protects credentials, tools/network and exclusive resources. Pi is a client. No identity issuer, sandbox, host provisioning, backup or generalized security/financial platform.

Use one configuration-defined HTTP transport and shared protocol handlers. No owned-policy mode is enabled with reachable unguarded commercial or unclassified egress; before integrated guard qualification, only positively trusted private-only topology with negative egress proof may enable that mode. Unknown trust is never eligible. In hybrid mode every commercial send, including legacy and prompt-bearing auxiliary paths, must pass the common fail-closed boundary: reserve scoped capacity, persist maximum financial exposure, recheck policy/config and consume exactly one authorization before any possible send. Rank permitted ready routes deterministically by configured private/included preference, expected cost and service constraints, independent of pending priority. Track scoped concurrency/rates, subscription fit and durable monetary liability separately, atomically reserving applicable scopes for the same attempt. A lost reservation after ranking refreshes/excludes the refused route and continues a finite round; only permitted alternatives may spend. Missing usage or no output does not prove non-execution. No automatic replay of ambiguity; independent replacement requires separate authorization and liability. Subscription-only requires upstream enforcement; predicted fit is not a guarantee. No paid test or account mutation is authorized here.
