## Description

The binary supports independent router and host-manager roles. One router owns the queue across the deployment. One manager controls each enrolled physical domain. The router owns pending demand and desired placement. The manager reports verified residency, accepts or refuses the exact operation, owns lifecycle and first write, and retains physical ownership through cleanup. Qualify exact recipe identity, instance replacement before send, lost acknowledgment, restart, stale generations and late cancellation. Uncertain work fences the affected domain.

[PR 94](https://github.com/ArborealML/Inference-Router/pull/94) qualified controlled in-process activation, held-domain independence and exact original-body delivery. Production enrollment, paired admission and verified send, recovery and owner-facing observations still require evidence. The native-switch milestone owns the paired production admission and sender proof and exclusive-residency integration. This milestone consumes that proof and qualifies authenticated manager transport before fixed-placement routing.
