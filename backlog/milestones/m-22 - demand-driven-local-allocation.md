## Description

The router selects desired context, physical recipe and admission concurrency for finite eligible work. The host manager checks feasibility and enforces the selected point. Use adopted, matched-work measurements from Tune. Demonstrate independent changes in context and concurrency, admission-only changes without restart, and safe expansion and contraction. Elective physical changes must improve completion after drain, cache loss and reconfiguration while preserving service floors. Qualify each mixed or staggered workload mode before enabling it.
